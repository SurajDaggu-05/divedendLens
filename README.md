\# DividendLens



A beginner-friendly dividend income tracker for Indian stock investors.



\## Architecture



\- Frontend: React + TypeScript + Vite

\- Backend: FastAPI + Python

\- Database: PostgreSQL

\- Background jobs: Redis + RQ

\- AI: Optional explanation layer

\- Swarm architecture: Lightweight distributed agents



\## Development



Frontend development: Cursor



Backend development: Antigravity
